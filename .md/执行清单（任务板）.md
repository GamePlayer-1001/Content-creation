# 内容生成输出项目 - 执行清单（任务板）

更新时间：2026-03-20
状态说明：Todo / In Progress / Review / Done / Dropped

---

## 一、总目标

将“内容生成输出”项目收口为一个：

- 以 **WebApp** 为主操作面
- 以 **串行工作流** 为主路径
- 保留 **工具箱** 的独立调用能力
- 同时具备 **CLI 通道**，便于未来自动化与批处理接入
- 低维护、可持续扩展、可人工把控

---

## 二、已确认原则

- 主操作面：WebApp
- 启动方式：bat 文件
- 双通道：WebApp + CLI
- 当前阶段：**暂不接入 cron**
- 主流程固定为 9 步
- 产品结构固定为：首页 / 内容生产工作流 / 工具箱
- 热点来源优先改为：Google Sheets
- 各阶段：自动承接 + 人工删改确认

## 任务 7：实现 CLI Runner
- **状态**：In Progress
- **目标**：为未来自动化、批处理、调度接入提供稳定入口
- **建议能力**：
  - 读取 Google Sheets 热点池
  - 执行单步或多步流程
  - 输出日志与结果摘要
  - 支持失败重跑
- **验收标准**：无需启动 WebApp 也能独立执行指定流程
- **2026-03-19 进展**：已新增 `app/cli/runner.js`（阶段查看、任务创建、任务推进、任务查询），WebApp 流程页已自动创建并携带 `taskId`，与 CLI 共用同一份任务状态文件。
- **2026-03-19 追加进展**：新增 `core/pipeline/step-executor.js`，CLI 支持 `task run-step` 直接执行已实现阶段（母稿生成 / 多平台改写 / 审核优化 / 导出）；任务 metadata 追加 `stageOutputs + artifacts + checkpoints`，WebApp 流程页顶部新增任务摘要卡片用于查看这些状态。
- **2026-03-19 再次追加**：CLI 新增 `task run-range --from --to` 区间执行，并补齐 `visual-generate` 阶段执行能力（支持 `--image-prompt/--image-type/--aspect-ratio` 等参数）；未配置图片 API Key 时，`run-range` 自动跳过 `visual-generate`。
- **2026-03-19 继续推进**：`run-range` 新增 `--on-error stop|skip` + `--retry N` + `--resume-from-failed`；Web 图片路由写回 `imageAssets/artifacts/stageOutputs/checkpoints`，流程页新增执行时间线与最近批量执行摘要。
- **2026-03-20 继续推进**：已实现 `layout-compose` 阶段（CLI `run-step` 可执行 + Web `/api/pipeline/compose` 排版输出），并在流程页新增“9阶段进度”可视化，任务状态与主流程定义进一步对齐。
- **2026-03-20 本轮推进**：完成前后端运行时目录对齐与冒烟验证：
  - 前端 Step2 引擎下拉改为动态读取 `/api/engines`，不可用引擎标记“未配置”并禁用选择。
  - 任务恢复时补齐 `hotspotSource` 回填；重新选热点时自动清空 `constraints`，避免旧约束残留。
  - 使用临时端口 `3211` 验证 `/api/pipeline/platforms|styles|hotspots` 与 `compose -> assemble` 闭环通过（`3210` 当前进程为旧实例，需重启主服务以生效）。

## 任务 12：将热点读取改造为“热点中心”
- **状态**：In Progress
- **目标**：把实时抓取复杂度转移到外部热点池
- **内容**：
  - 读取 Google Sheets 热点池
  - 支持筛选、查看、选择、导入
  - 补录热点详细内容
- **验收标准**：热点模块更稳定、更轻、更适合创作导入
- **2026-03-20 进展**：已打通热点中心最小闭环：
  - 阶段1：`hotspot-list`（Google Sheets + 手动热点池回退）
  - 阶段2：`hotspot-select`（任务绑定已选热点）

- **2026-03-20 补充进展**：Web Step1 已支持结构化补充字段（`facts / constraints / materials`）并写回任务状态；CLI `task run-step` 同步支持三字段输入，已完成真实任务冒烟验证。
- **2026-03-20 迭代补充**：`HOTSPOT_SOURCE` 配置已在服务层生效；当请求 `source=auto` 时会优先遵循环境默认来源（仍保留 Google 失败回退手动池能力）。
