发现很多人不知道怎么防止 Claude 被封号  
点击左下角头像点开 Settings——Privacy  
关闭Location metadata 和 Help improve Claude，这两个选项默认开启，会向 Antropic 官方持续传输 ip 地址信息和用户数据，如果🪜节点不稳定很容易被官方抓到封号，和身边的小伙伴分享后基本没有被封号了（当然，频繁使用第三方工具薅 oauth key作死除外）
