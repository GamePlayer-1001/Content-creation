最近在 GitHub 上挖到了一个堪称“开挂”的开源多模态工具集——Generative-Media-Skills。  
  
这绝对是专为 AI Agent 量身定制的终极杀器。  
  
以前搞多模态开发，自己对接一堆乱七八糟的 API 能让人抓狂。  
  
现在，它一口气帮你打通了 100+ 个主流 AI 模型。不管是 Midjourney v7、Flux，还是视频领域的王牌 Kling 3.0 和 Veo3，全部被整合到了底层。  
  
你只需要在终端敲敲键盘，你的 AI 助手秒变全能导演。  
  
更硬核的是，这玩意儿绝不是简单的 API 套壳，它自带一层专业级专家技能库。  
  
不懂电影导演怎么运镜？不知道怎么设计高级 UI 界面和矢量 Logo？  
  
没关系！这套项目把极其考验专业功底的逻辑，全封装成了开箱即用的 CLI 脚本。所有基元全部委托给高性能的 muapi-cli 处理，彻底干掉恶心的 curl 请求和样板代码。  
  
日常使用体验只能用“丝滑”来形容：  
  
支持本地文件自动上传 CDN 处理，生成结束后，只需一个 --view 标志，就能自动调用系统查看器打开预览，所见即所得。  
  
但它真正的“王炸”，是对 MCP 服务器协议的完美支持。  
  
只需要跑一条 muapi mcp serve 命令，就能瞬间向 Claude Desktop、Cursor 或任何兼容 MCP 的智能体暴露 19 个结构化的媒体工具。  
  
这相当于一键给你的本地大模型接上了“好莱坞级别的眼睛和嘴巴”，实现无缝的智能体管道对接。  
  
如果你也想让自己的本地 AI 工具链原地起飞，具备最顶级的图片和音视频生成能力，千万别错过这个神器。  
  
项目传送门：GitHub 直接搜索 SamurAIGPT/Generative-Media-Skills。  
  
搞定多模态开发内耗，有这一套就足够了。
