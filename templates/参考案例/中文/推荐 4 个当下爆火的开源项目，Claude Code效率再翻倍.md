最近Claude Code相关的开源库太火了！

我找了 **4个** 比较火的，推荐给大家。

经常看我文章的朋友都知道，我一般一篇只发一个的，实在不想等了，直接今天都发出来吧， **有大家特别感兴趣的我可以再单独出一期完整版。**

**badclaude**

这项目有点意思啊，在推特上两条爆的帖子加起来有 **千万播放量** 了。

这作者做了个鞭子去调教Claude Code，让它更快工作。

![](https://p26-sign.toutiaoimg.com/tos-cn-i-6w9my0ksvp/eee999fb6424433cbbfcaec3d091b2f4~tplv-tt-origin-web:gif.jpeg?_iz=58558&from=article.pc_detail&lk3s=953192f4&x-expires=1776221915&x-signature=rVYtq4qfki1V3imyvLAX0uyrvdk%3D)

**项目简介**

badclaude是一个给Claude Code设计的增强型提示词指令集和越狱式自定义技能库。

它通过解锁了官方工具在系统修改、高危命令执行及复杂代码重构中的限制，通过一套极具攻击性的指令体系，让Claude Code绕过常规的安全防御性回复，获得更多权限，从而在处理深度系统架构调整、遗留代码重构及自动化运维任务时展现出极高的执行效率。

**项目链接**

```
https://github.com/GitFrog1111/badclaude
```

**gstack**

几天就点了66k星星。

**项目简介**

gstack是一套开源的Claude Code专家技能包，它可以把AI转化为一支全职能的虚拟工程团队。

该项目集成了23个高度专业化的角色，如CEO、设计师、架构师、QA等。

通过一套极具主见的指令工作流，覆盖了从产品构思、技术规划、代码实现到视觉测试的全生命周期。

每日交付万行代码变成一件简单的事，帮开发者以CEO的视野和资深专家的精度进行开发。

**项目链接**

```
https://github.com/garrytan/gstack
```

**claw-code**

这个就比较有趣了。

这个库就是我前几天发的claude code代码泄露里的那个。

绝对是最快突破10w星星的开源项目了。

Anthropic到处投诉发函，让下掉他们的代码，这项目的作者灵机一动， **干了三件事，保下了这个库。**

1、改名，之前这个库是长下面这样的。

2、免责声明，撇清了一切关系。

3、层层递进，这肯定是最牛的一点了，这作者为了让这个库活下来，连夜把所有代码都改掉了，哈哈哈哈，很疯狂的。

**项目链接**

```
https://github.com/ultraworkers/claw-code
```

**everything-claude-code**

14w星星。

**项目简介**

Everything Claude Code是一个开源的AI编程Agent增强系统，是针对Claude Code、Cursor、OpenCode 等工具的一站式性能优化和技能扩展方案。

项目由Anthropic黑客松冠军开发，通过提供一套结构化的智能体子集、自动化钩子、安全扫描机制和内存持久化方案，把原本碎片化的AI编程体验转化成高度专业、可预测且具备持续学习能力的工程化流水线。

教程也做的很棒。

**项目链接**

```
https://github.com/affaan-m/everything-claude-code
```
