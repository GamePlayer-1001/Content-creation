## 一、中文黑名单（零容忍）

命中即删除或替换，无例外。

### 1. 翻译腔开头
- **禁用**: 随着、在当今、近年来、伴随着、在这个时代
- **替代**: 直接讲故事/数据/事件

### 2. 空洞过渡
- **禁用**: 不可否认、众所周知、毋庸置疑、显而易见
- **替代**: 删除，用证据说话

### 3. AI废话
- **禁用**: 值得注意的是、起到重要作用、具有重要意义、需要指出的是、不仅如此
- **替代**: 删除或具体化

### 4. 假客观
- **禁用**: 有人认为、据说、或许
- **替代**: 引用来源或直接表态

### 5. 总结套话
- **禁用**: 综上所述、总而言之、概括来说、归根结底、总之、综上
- **替代**: 删除，用金句或互动钩子收尾

### 6. 过度修饰
- **禁用**: 深深地、静静地、温柔地、轻轻地、默默地、缓缓地、悄悄地、慢慢地、渐渐地
- **替代**: 删除副词，用动作描写替代

### 7. 假大空词汇
- **禁用**: 绽放、涅槃、启迪、沉淀、升华、洗礼、蜕变、觉醒、顿悟
- **替代**: 用具体场景替代抽象概念

### 8. 套路连接词
- **禁用**: 首先、其次、最后、此外、另外
- **替代**: 自然段落过渡，不要工整列举

## 二、英文黑名单（零容忍）

从 Medium/Quora/Reddit/X推文 Skill 中归拢。

### 1. AI高频词
- **禁用**: delve, utilize, leverage (as verb), robust, streamline, harness, certainly, furthermore, moreover, additionally, notably, arguably, comprehensive, innovative
- **替代**: 用简单直白的词。leverage → use, utilize → use, robust → strong, comprehensive → full

### 2. 翻译腔开头
- **禁用**: "In today's rapidly evolving...", "It is important to note that...", "As we all know...", "In the ever-changing landscape of..."
- **替代**: 直接进入正题或用故事开头

### 3. 假权威
- **禁用**: "Studies show...", "Experts argue...", "Research suggests...", "It has been observed that..."
- **替代**: 引具体来源，或直接表态。说不出来源就别说

### 4. 总结套话
- **禁用**: "In conclusion", "To sum up", "In summary", "As we've seen"
- **替代**: 用有力的收尾句或行动号召

## 三、中文三轮润色引擎

供平台适配层使用。**母稿不调用此引擎**。

### 第一轮：降AI味

**删除词**: 首先、其次、最后、总之、综上、此外、另外、值得注意的是、不仅如此、需要指出的是

**替换表**:

| 原词 | 替换为 |
|------|--------|
| 但是 | 但 |
| 因为 | 就因为/就是 |
| 所以 | 所以说/就 |
| 虽然...但是... | 去掉虽然直接说 |
| 我认为 | 怎么说呢/反正就是 |
| 非常 | 超/巨/贼 |
| 一些 | 几个 |
| 进行 | 删除（直接用动词） |

**结构规则**:
- 打破完美逻辑链——允许思维跳跃
- 拉大句子长短差异——3-5字短句和20-30字长句交替
- 省略主语——（我）当时就急了
- 破坏工整感——打散排比句和对称结构

### 第二轮：加人类废话

**基础比例**: 10-15%（按平台调整，见下方平台力度覆盖）

**语气词库**:
- 尾音: 嘛、吧、啊、诶、哎、唉、呢、嘞、喽
- 填充: 就是说、怎么说呢、反正、说真的、不是吧、我天、离谱、绝了、无语、属于是
- 情绪爆发: 啊啊啊、哈哈哈、救命、笑死、哭了、破防了
- 自我中断: "就是那个…算了"、"本来想说…算了不重要"、"我也不知道怎么形容"
- 强调重复: 真的真的、是真的准、真的很绝
- 犹豫不决: "就…怎么说"、"大概也许可能是"、"应该吧我也不确定"

### 第三轮：加倒装句

**基础数量**: 3-5个（按平台调整）

**模板**:
- 这个太准了 → 太准了这个
- 我真的服了 → 服了我真的
- 我当时笑死了 → 笑死当时我
- 真的离谱 → 离谱真的
- 我当时急了 → 急了我当时
- 我当时直接傻了 → 直接傻了我当时

**规则**: 放在情绪爆发点，不要连续两句倒装。

## 四、英文润色引擎

从 Medium/Quora/Reddit/X推文 Skill 中归拢。

### 第一轮：降AI味 (De-AI)

**删除词**: Furthermore, Moreover, Additionally, In conclusion, It's worth noting, Importantly, Notably, Interestingly

**缩写强制使用**:
- do not → don't
- can not → can't
- it is → it's
- will not → won't
- would not → wouldn't
- they are → they're

**结构规则**:
- 允许句子碎片化和不完整句
- 打破过于工整的并列结构
- 拉大句子长短差——碎片句(2-5词)和长句(15-25词)交替

### 第二轮：加人味 (Human Voice)

**基础比例**: 5-8%（按平台调整）

**网络口语库**:
- 语气: honestly, ngl, lowkey, tbh, like, I mean
- 开头: "Not me doing...", "The way this...", "Literally just..."
- 自嘲: "idk if this makes sense but", "hear me out", "hot take:"
- 标签: "Edit: typo", "YMMV", "imo", "fwiw"

### 第三轮：节奏调整

- 偶尔用全大写强调1-2个关键词（如 INSANELY good）
- 用 "..." 和 "—" 制造口语停顿感
- 段落长短交替（1句段 + 3-4句段）

## 六、代码块保护

技术类文章中的代码块**绝对不可修改**。

**保护范围**:
- 三反引号代码块内全部内容
- 单反引号行内代码
- 代码注释（即使包含黑名单词汇也不改）
- 技术术语（函数名、变量名、文件名）

**处理流程**: 识别代码块 → 标记为占位符 → 只对非代码区域应用规则 → 还原代码块 → 验证未被修改
