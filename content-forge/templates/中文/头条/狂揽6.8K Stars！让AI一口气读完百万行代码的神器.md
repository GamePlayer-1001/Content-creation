## 这玩意儿到底是个啥？

**Claude Context** ，GitHub上狂揽 **6801 Stars** ，由向量数据库大厂 Zilliz 出品，纯 TypeScript 打造。它的口号简单粗暴： **"Your entire codebase as context"** ——把你整个代码库变成AI的上下文。

说白了，它给Claude装了个"外接大脑"。不再是AI瞎猜你在问哪段代码，而是让它拥有 **语义级代码搜索能力** ——你用人话描述需求，它秒级定位到相关代码，精准投喂给AI。

比如你说："找一下处理用户登录的函数"，它不会傻乎乎地全文检索"login"这个关键词，而是真正理解"用户认证"、"session管理"、"token验证"这些语义相关的代码块。

## 省钱！省到就是赚到

小编算笔账：如果你每次问AI都把整个src/目录塞进去，几十万token哗啦啦就没了。Claude Context的骚操作是—— **先把代码库塞进向量数据库，只把相关的代码片段拎出来给AI看** 。

官方评测数据显示，同等检索质量下能 **省40%的token** ！这意味着你的API账单直接打六折，还能在有限的上下文长度里塞更多有效信息，AI回答质量反而更高。

这波啊，这波是 **花小钱办大事** 。

## 用起来有多简单？

配置一条命令，开箱即用：

```
claude mcp add claude-context \
  -e OPENAI_API_KEY=sk-your-key \
  -e MILVUS_ADDRESS=your-endpoint \
  -e MILVUS_TOKEN=your-token \
  -- npx @zilliz/claude-context-mcp@latest
```

然后进项目目录，跟Claude说：

```kotlin
Index this codebase
```

等它建好索引，你就可以开始 **人话编程** 了：

```bash
Find functions that handle user authentication
```

Claude会收到精准的代码片段，而不是整个代码库的噪音。

## 全家桶支持，不挑编辑器

担心只用Claude Code？格局打开！这项目支持 **几乎所有主流AI编程工具** ：

- **Cursor** 、 **VS Code** 、 **Windsurf** ——编辑器党狂喜
- **Gemini CLI** 、 **Qwen Code** 、 **OpenAI Codex CLI** ——命令行战士必备
- **Cherry Studio** 、 **Cline** 、 **Roo Code** 、 **Augment** ——各种AI助手通吃

甚至还能直接集成到 **LangChain/LangGraph** 里自己搭工作流。一句话：你用什么工具，它就跟到哪。

## 技术底裤扒一扒

Zilliz毕竟是做向量数据库出身，技术栈相当扎实：

- **混合搜索** ：BM25关键词匹配 + 稠密向量语义搜索，双管齐下
- **AST智能分块** ：不是按行数瞎切，而是基于抽象语法树理解代码结构
- **增量索引** ：用Merkle树只更新改动的文件，百万行代码库也能秒级同步
- **多语言支持** ：TypeScript、Python、Java、Go、Rust……祖传代码什么语言都能啃

背后接的是 **Zilliz Cloud** 或开源的 **Milvus** 向量数据库，规模再大也扛得住。
