## 一、母稿质量门控

聚焦内容深度和传播力，**不评估口语化程度**（口语化是平台适配层的事）。

### 四维评分

| 维度 | 评估标准 |
|------|---------|
| **钩子强度** | 前3句能否制造好奇缺口？是否使用了三种钩子之一？ |
| **洞察密度** | 每段是否有新信息？是否有反直觉洞察？删掉任何一段是否有损失？ |
| **传播基因** | 是否有让人想分享的点？有无可截图金句(<=20字)？转发动机是什么？ |
| **论证深度** | 有无具体细节(时间/地点/数据/案例)？论证是否有证据链？ |

- **通过分**: 每项1-10分，平均 >= 8
- **最大循环**: 3轮（<8分回流修订，3轮后输出"未达标"版本）

## 二、平台质量门控

四维评分 + 四轨审核双保险。比母稿门控更严格。

### 四维评分（快速评估）

| 维度 | 评估标准 |
|------|---------|
| **钩子强度** | 前3秒能否抓住注意力 |
| **互动设计** | 是否有明确的评论/收藏触发点 |
| **人味指数** | 是否像真人写的，AI味重不重 |
| **趣味度** | 看完是否想分享/收藏 |

- **通过分**: 每项1-10分，平均 >= 9
- **最大循环**: 5轮

### 四轨审核（深度检测，总分100，>=70通过）

来源: CAT5_Factory advanced-quality-gate v4.0

#### Track 1: SEO审核（权重20%，通过线14分）
- 关键词密度 1-2%
- LSI覆盖率 >= 70%
- 关键词位置：标题+首段+结尾
- 内链数量合适

#### Track 2: AI痕迹检测（权重30%，通过线21分）
- AI高频词汇扫描
- 套路句式识别
- 真实感评估
- 排比对仗检查
- 参考下方"AI检测四维度"

#### Track 3: 爆发度检测（权重25%，通过线17分）
- 短句比例 25-35%
- 最长连续长句 <= 5句
- 情绪爆点 >= 2个/千字
- 被动语态 < 15%
- 段落节奏有变化

#### Track 4: 传播潜力（权重25%，通过线17分）
- 共鸣点数量 >= 2个
- 转发动机强度（社交货币/情绪宣泄/实用价值/身份认同）
- 金句质量（简短有力 <= 20字）
- 话题性（能否引发讨论）

### 平台特化门控

部分平台有维度差异：

| 平台 | 维度差异 | 说明 |
|------|---------|------|
| GitHub | 三维(删"人味指数") | 技术内容天然真实 |
| 朋友圈 | 三维(删"人味指数") | 短文本不需要 |
| X推文 | "趣味度"替换为"X算法适配" | 正面/建设性+互动引导 |
| 知乎 | 论证深度权重提高 | 知乎用户专业度高 |

## 三、对抗性审查（Cold Editor）

来源: CAT5_Factory cold-editor。母稿创作阶段使用。

**身份**: 冷酷主编——没有情面可讲，只有标准。不写作，只审判。

### 三问攻击

| 攻击 | 目标 |
|------|------|
| "为什么我要继续看？" | 钩子是否在前3句创造了好奇缺口 |
| "这个观点我早就知道了" | 是否有真正的反直觉洞察，还是在重复常识 |
| "看完了所以呢？" | 是否有让人想分享/收藏的理由，金句在哪 |

### 严重度分级
- **致命级**: 钩子无力 / 核心观点是常识 / 无传播点 → **打回重写**
- **优化级**: 措辞可改进 / 结构微调 → **通过**

最多2轮 Writer <-> Editor 循环。

---

## 四、传播潜力评估

来源: CAT5_Factory advanced-quality-gate Track4。

### 共鸣点检测
- 是否触及读者痛点
- 是否有"你有没有过..."类代入感表达
- 是否描绘读者的心声

### 转发动机检测
- **社交货币**: 分享显得我很XXX
- **情绪宣泄**: 说出我想说的
- **实用价值**: 对别人有用
- **身份认同**: 这就是我

### 金句质量
简短有力(<=20字)、有观点有态度、非常见鸡汤。

## 五、AI检测四维度

来源: CAT5_Factory ai-detector。供洗稿/优化去AI/质检参考。

| 维度 | 权重 | 检测对象 | 备注 |
|------|------|---------|------|
| **AI高频词汇** | 30% | 过度修饰、假大空词汇、翻译腔/书面语 | 对照 writing-rules.md 黑名单 |
| **套路句式** | 25% | 时间类、选择类、条件类、因果类套路 | 对照 tropes.md 句式结构类 |
| **真实感** | 30% | 具体细节占比、口语化程度、真实瑕疵 | **完美无瑕 = 0分(高危!)，有瑕疵反而得分高** |
| **排比对仗** | 15% | 排比句检测、结构完美度 | 过于工整的结构 = AI特征 |

## 六、反AI检测策略

来源: CAT5_Brain + CAT5_Factory。8项操作策略。

1. **打破对仗句式** — 避免 A,B;A,B 的平行结构
2. **增加口语碎碎念** — 插入无意义的感叹/自嘲
3. **减少概括性总结句** — 删除"总的来说""综上所述"
4. **用具体场景替代抽象概念** — "效率提升50%" → "原来半天的活午饭前搞完"
5. **术语口语化** — "吃什么进去的"替代"输入了什么数据"
6. **陈述→思考过程** — "我琢磨过" "后来我想明白了"
7. **格式化→随意化** — 去掉工整列表，变成自然段落
8. **逻辑递进→故事展开** — 时间线叙事替代论证

**目标检测器**: 腾讯混元、GPTZero、ZeroGPT
**目标分数**: <= 30% AI检测率
